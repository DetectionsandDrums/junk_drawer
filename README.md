# junk_drawer

A catch-all repo for the useful odds and ends that don't belong anywhere else —
templates, scripts, checklists, and small tools worth keeping and sharing.

Nothing here is precious or heavily maintained. It's the digital equivalent of the
kitchen drawer everyone has: the stuff you reach for now and then and are glad you
kept. Take anything that's useful, adapt it to your needs, and don't worry about
using it "correctly."

---

## Contents

| Folder | What's in it |
|---|---|
| [`Job_hunting_tools/`](./Job_hunting_tools/) | Editable tools for running a job search — currently an Excel application tracker with a self-updating dashboard and funnel stats. |
| [`Drum_related/`](./Drum_related/) | Reference material for drummers — currently a detailed breakdown of Superior Drummer 3's sound packs, instrument by instrument. |

More drawers get added over time. Each folder has its own README explaining what's
inside and how to use it.

---

## How to use this repo

- **Browse** the folders above and open whichever one is relevant.
- **Copy what you need.** Everything here is meant to be taken and modified — treat
  each file as a starting point, not a finished product.
- **Make it yours.** Rename things, delete what you don't use, restructure freely.

---

## A note on shared templates

Some items here are templates you fill in with your own information (the job tracker,
for one). Once you populate a template it holds *your* data — keep your working copy
private and share only the blank version. The blank templates in this repo are safe
to copy and pass along.
